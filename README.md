# Kevin AI 💬

A modern real-time AI chat application inspired by the WhatsApp messaging experience. Kevin AI allows users to chat with each other instantly and interact with Gemini AI by simply mentioning **@ai** in the conversation.

## ✨ Features

* 💬 WhatsApp-like real-time chat interface
* 🤖 Gemini AI integration using **@ai**
* ⚡ Real-time messaging with Socket.IO
* 🔐 User authentication
* 🌙 Clean and intuitive chat experience
* 🚀 Fast frontend deployment on Vercel
* ☁️ Backend hosted on Render

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Socket.IO Client

### Backend

* Node.js
* Express.js
* Socket.IO
* Gemini API

### Database

* MongoDB

### Deployment

* Frontend: Vercel
* Backend: Render

## 🤖 Using AI

Mention **@ai** in any chat message and Gemini AI will automatically generate a response.

**Example:**

```text
@ai Explain JavaScript promises.
```

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/kevin-ai.git
cd Kevin-AI
```

### Install dependencies

Frontend

```bash
cd FRONTEND
npm install
```

Backend

```bash
cd BACKEND
npm install
```

### Environment Variables

Create a `.env` file inside the server directory.

```env
PORT=5000

GEMINI_API_KEY=your_gemini_api_key

JWT_SECRET=your_secret_key

MONGODB_URI=your_mongodb_connection
```

### Start the application

Frontend

```bash
npm run dev
```

Backend

```bash
npm run dev
```
